# 小班 Xiaoban

**住在桌角，陪你工作，也提醒你休息。**

小班是一款 Windows 桌面生活搭子，把角色互动、便利贴、时间记录和日常提醒放在同一个小工位里。

> 当前版本：1.0 RC1 小卡片体验版。仍在完善 Windows 实机体验，欢迎试用与反馈。

## 下载与开始

进入 **[下载页面](https://github.com/JIAAXINYU-AI/xiaoban-desktop/releases)**，下载 `Xiaoban-Windows-v1.0.0-rc.1-compact.zip`。
不要把 GitHub 自动生成的 `Source code` 压缩包当作安装包。

1. 已运行旧版时，先在托盘菜单退出。
2. 将下载的 ZIP **完整解压**到一个文件夹。
3. 双击 `Xiaoban.exe`。请保留旁边的 `assets` 文件夹。
4. 找不到小班时，按 `Ctrl+Alt+B`，或双击系统托盘中的小班图标。

需要 Windows 与 .NET Framework 4.8；本版本不支持 macOS、Linux。尚未完成所有 Windows 版本、多屏与 DPI 的兼容性验收。

## 我能陪你做什么？

| 小工具 | 日常使用场景 |
| --- | --- |
| 键盘跟随与摸头 | 工作时有一个会回应的小搭子 |

| 勿扰与备份 | 自己决定陪伴强度，保管自己的记录 |

## 为什么做小班？

我的设计目标是让工具就在手边，让陪伴可以安静。界面采用小卡片、圆角与温暖配色；常用功能通过角色和桌边物件进入，也保留菜单入口。

这次迭代把便签宽高缩到原来的85%，其余工具卡片缩到88%，减少占用桌面的面积。角色形象与原有功能保留。

开发过程使用 AI 辅助编程；产品取舍、交互检查与迭代由创作者持续推进。这是一个仍在接受真实体验检验的个人项目。

## 数据与隐私

记录保存在本机 `%LOCALAPPDATA%\Xiaoban`。更新程序时不需要搬动记录。

键盘跟随通过按键事件触发动作，当前实现不解析具体键值或输入文字；可在设置里关闭。用户主动输入便签等功能的内容会按功能保存在本地。请勿在公开 Issue 上传私人便签、备份或含私人内容的截图。
